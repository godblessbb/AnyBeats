## 1. 根因（在 v3 构建产物上实测复现，截图在证据目录 `before/`）

**打字溢出到下一拍。** `WordInput` 回车调 `store.commitText(abs, v)` → `core/grid.ts` 的 `fillTexts(grid, abs, chars)`：
它把全曲里 `abs` 之后的**所有**字当成目标，一个字一个位置往后填，不看拍的边界；填完 `startEdit(next)` 还自动跳到下一个字接着改。
实测：第 2 小节第 1 拍「凌晨三点」打「一二三四五六」→ 第 2 拍「街灯」被改成「五六」。

**加段落永远是 Verse。** `LyricsGrid.tsx:452` 写死了 `store.addSection('verse')`。

**整列选中跨段落乱**（用户截图里的三个现象 + 一个操作上的坑）：
1. 每一行各画一圈粗橙框：`App.css:237` `.cell.sel-in { box-shadow: inset 0 0 0 2px }`，每个选中的格子自己画框，九行就是九个框；
   段落标题那一行没有格子，所以在 Hook 标题处断开。
2. 第 2 拍上的橙色竖条：拍头高 42px，上面 26px 是拍号按钮（选整列），下面 16px 是 4 个 16 分小按钮（`data-role="sub-tick"`，
   `store.setBand`）。点到拍头下半截不会选整列，而是给整首标出「第 2 拍第 2 个 16 分」一条（`.sub.on` 橙底 + 每个格子里一条 `.band`），
   而且这个标记是开关、点别处不消失。
3. 后面段落的空行也被框上：`core/rhymeRules.ts` 的 `columnKeys` 返回**每一个**小节的这一拍，空格子也算；涂色时又被跳过。
   实测选第 3 拍：第 1 小节（Intro 里这一拍是空的）也被选中。
4. 点了拍号以后 `selectColumn` 把选法切成「整列」（`selMode: 'col'`），之后**随便点哪一格都会再选一整列**，看起来就像格子点不准。
   `selectRow` 同理会切成「整行」。

**格子里一个个小框又笨又丑。** 每个字是一个带边线的字框（`.slot.word`），单击字框直接进入改字（`clickCell` + `startEdit`），
单击格子空白处才是选格子；同一格里有两种点法、还有多个点击目标。

## 2. 新设计

### 2.1 一拍 = 一格
- 格子里不再画字框。字直接写在落点上（左边 = 格左 + tick/48 × 格宽 + 1px），韵脚字用它那种颜色的深色写、加粗；还没填的字画一条短下划线；
  韵脚位还没填时照旧显示韵母（`ang`）。
- **单击**一格 = 选中这一拍；**双击** = 改这一拍的字。格子里没有别的点击目标（改长度的把手除外）。
- 选中只画**一个框**（2px 强调色 + 一圈浅色光晕），画在格子上面一层，格子原来的颜色照样看得见。格子自己不再画选中框。

### 2.2 整列 / 整行
- 拍头整格是**一个按钮**：点哪里都是选这一拍整列；下面的 16 分刻度只是标尺，不能点。`setBand` 这个功能去掉。
- 整列 = 整首这一拍里**有东西的格子**（有字，或有前面拖过来的拖音）；完全空的格子不选（第 1 小节、Outro 里的空行）。
- 一段连续的小节画成一个框；跨段落也算连续（段落标题只是夹在中间的一行），框穿过标题，标题那一行同一列垫一层浅色，不断开。
- 选中的拍头本身也高亮（浅橙底 + 拍号变强调色）。
- 点拍头 / 小节号**不再切换**「选格子」的选法；工具条上的「整列」按钮去掉，剩「单格 / 整行 / 框选 / 反选」。

### 2.3 双击改字：打几个字排几个字，绝不写进下一拍
双击一格，整格变成输入框，里面是这一拍现在的字（没填的位置不算）。按回车：

| 打了几个字 N | 这一拍原来有几个字的位置 S | 结果 |
|---|---|---|
| 0 | 任意 | 清掉这一拍所有字的文字，位置不动 |
| N ≤ S | — | 按原来的节奏，前 N 个位置依次填，后面多的位置清成空（位置保留） |
| N > S，N ≤ 4 | — | 这一拍重新平分成 N 份：1 = 1/4（48 tick）、2 = 1/8（24）、3 = 三连（16）、4 = 1/16（12） |
| N > S，N ≤ 4，这一拍里有锁住的字 | — | 不重排，提示「这一拍有锁住的字，不能重新分；先解锁，或只打 S 个字以内」 |
| N > S，N > 4 | — | 什么都不写，提示「一拍最多 4 个字……先到「① 铺 flow」把这一拍分细」 |

- 只动这一拍：重新平分时，这一拍里原来的字被替换，最后一个字结束在本拍末尾；前一拍拖进这一拍的字缩到本拍开头为止
  （这一拍的时间归新字）；**下一拍的字一个都不动**。
- 一次回车 = 历史里一步，可以撤销。输入框下面实时说明回车后会怎么排（N 变了提示跟着变）。
- `Esc` 取消；输入框失焦 = 确定（和现在一样）。

### 2.4 拖音 = 同色浅底
- 字唱多长：比一个 16 分（三连 16 tick）长的字，从它的落点一直铺一块**同色浅底**到它结束；字靠左写在浅底开头。不再画细线。
  普通字的浅底 = 字色的淡色；韵脚字 = 它那种颜色（和韵脚格的底色同色相，深一档）。
- 浅底跨格线就接着铺；跨过一小节的末尾，就从下一行第一格左边接着铺。
- 改长度：第 1 步选中的字、第 2 步指针停在字上时，字（或浅底）的右边缘出现一个把手；往右拉长、往左缩短，吸附到当前精度
  （第 2 步用第 1 步选的精度），拖的时候先用强调色浅底预览，旁边小提示写「拖到 第几小节第几拍 · 第几个 16 分」。
- 数据模型、押韵规则都不变：字还是「起点 tick + 持续 tick」；押韵还是按格子里最后 n 个字算，拖的长度不算。

### 2.5 段落类型
「+ 段落」点了弹菜单：Intro / Verse / Hook / Bridge / Outro（各带一句中文说明），加在最后、4 小节；同类型已有就自动编号（Verse 2）。

### 2.6 打开在哪一步、步骤按钮
- 打开作品（包括新建、切换作品、导入）时：作品里**一个字都没写**（所有字的文字都是空的，或者还没铺字）→ 在「① 铺 flow」；否则在「② 填字和韵脚」。
- 步骤按钮：当前步骤用强调色实底（和播放键同一个颜色），数字圈反白；没选的那个照常。只用已有的颜色 token。

## 3. 第二段的实现计划（已按此实现）
- `core/grid.ts` 加一个纯函数：把 N 个字排进某一拍（够就按原节奏填、不够就平分重排、碰到锁就报错），单测覆盖 N = 0–5、
  S 大于 / 等于 / 小于 N、有锁、前一拍拖进来、本拍最后一个字拖进下一拍，以及「下一拍的字逐字节不变」。
- `editorStore`：`commitBeatText(bar, beat, text)` 一步 `exec`；`selectColumn` 只选有东西的格子、不改 `selMode`；`selectRow` 不改 `selMode`；
  `addSection(kind)` 由菜单传；打开作品时按有没有字定步骤。删掉 `band` / `setBand`。
- `LyricsGrid.tsx`：格子里画字 + 浅底；单击 / 双击；拍头一个按钮；选中框按量出来的格子位置画成连续的几段；段落菜单。
- `e2e/check_app_v31.py`：在 dist 上用真实鼠标键盘操作——每种 N 打字后下一拍的字不变（另做一次反向探针：故意往别的格子写，确认检查会报错）；
  点拍头跨 Verse / Hook 选整列，框正好是那一列；没有 1/16 竖条；加段落五种都能加；打开空作品在第 1 步。
