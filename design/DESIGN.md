## 1. 设计原则

1. **首屏就是写词的地方。** 每个画面（包括录音、AI、导出）左边/上面都是歌词网格，其它东西都放进旁边的面板（桌面）或底部抽屉（手机）。
2. **一行 = 一小节 = 16 个 1/16 拍格。** 说唱一小节一般就是一句，句尾对齐，押韵一眼看出来。
3. **一个时钟、一个播放键。** 伴奏、节拍器、导唱、录音、歌词高亮全挂在同一条时间线上。
4. **DAW 式的密度，Alphie 式的克制。** 中性色全用 Alphie token；只有一个强调色（朱橙 `#C2410C`，深色 `#FB8A4C`），不用紫色、不用渐变、不堆卡片、标题不用全大写。
5. **AI 是建议，不是改写。** AI 结果先以虚线行预览，采用了才写进歌词，采用后也能撤销。

## 2. 信息架构

```
画布（iframe）
├─ 顶栏 44px：作品名 + 自动保存状态 │ 撤销 / 重做 │ 走带：回到开头、播放(唯一)、录音、位置(小节·拍·1/16)、BPM(自动/±1)、节拍器、导唱、循环 │ 当前 Worker │ 导出
├─ 轨道条：伴奏波形（小节标尺、段落标记、首拍偏移旗、播放头）+ 伴奏/节拍音量；录音时展开成 take 泳道 + 输入电平
├─ 主区
│  ├─ 歌词网格（段落 → 小节行 → 16 格），底部「+ 小节」「+ 段落」
│  └─ 右侧面板（296px，宽桌面 320px）：押韵 │ AI 写词 │ 录音；点「导出」换成「工程与导出」
└─ 状态栏 26px：当前画面的快捷键 + 网格信息

手机（356×624）：顶栏 → 走带条 → 轨道条（只有伴奏）→ 网格 → 底部标签栏（写词 / 押韵 / AI / 录音 / 工程）

```

## 3. 主要流程：写 → 唱 → 听 → 导出

1. **准备**：在轨道条拖入或「替换」伴奏 → 自动检测 BPM（顶栏 BPM 旁标「自动」，±1 手动校）→ 拖动轨道条上的蓝色「1」旗设第一拍偏移（显示在伴奏名下：首拍 +120ms）。
2. **写**：点格子直接打字；方向键移动；`-` 延音、`_` 空拍、`A` 重音；句尾自动按韵母标色。右侧「押韵」给出同韵候选（本地韵表），拖进格子。卡住了切到「AI 写词」续写 / 改押韵 / 调字数，预览满意再采用。
3. **唱**：按录音（R）。第一次会先走延迟校准；戴蓝牙耳机会提示。跟伴奏录多遍，每遍是一条 take，星标选用、拖两端括号裁头尾。
4. **听**：按播放，伴奏 + 选用的 take 同步走，歌词逐格高亮。
5. **导出**：顶栏「导出」→ txt / LRC / 工程文件 / Reaper 工程 + 分轨。

### 网格细节

- 16 格一行，每 4 格一条深一点的拍线，小节头更粗；格宽 34px（宽桌面 38px，手机 19px）。
- 一格一个字。`⌒` 延音画成一条横线连到下一个字；`∅` 空拍显示灰色 ∅；空格子就是没字。
- 重音：字下面一个小圆点（`A` 键或双击切换）。
- 押韵标色只标**句尾最后一个字**：浅色底 + 底部 3px 色条 + 行尾韵母标签。颜色按韵母分配，同一首歌里同韵同色；色板避开紫色区。字本身始终是正文颜色，保证对比度。
- 段落头：名字、小节数、本段韵脚统计、「⋯」菜单（重命名 / 复制段落 / 删除）。小节号左边的点阵是拖动把手。

## 7. 视觉规范

- **Token**：`design/mockups/shared.css` 第 1 节原样抄 Alphie `design-tokens.css`（浅 / 深两套中性色、状态色、字号、行高、字体、间距、圆角、阴影），第 2 节是 AnyBeats 的语义层，只用 CSS 变量引用，不外链任何资源。
- **强调色**：朱橙 `#C2410C`（色相约 20°），白字对比 5.2:1；深色模式 `#FB8A4C` 配深字。和 Alphie 的中性灰 + 状态色放一起不跳，又和 Alphie 自己的 indigo 区分开。
- **次要文字**：Alphie 的 `#999999` 在白底上不到 4.5:1，所以要读的次要文字用 `#5E5E5E`（深色 `#AEAEB2`），`#999` 只给装饰性信息。
- **韵母色板**：蓝 / 绿 / 粉 / 青 / 金，避开 250–310° 紫区；色只上在底色和色条上，字保持正文色。
- **字号**：正文 13px，歌词字 16px（手机 14px），位置数字 15px 等宽，标签 11–12px。
- **不做的事**：紫色主色、紫色渐变、满屏卡片、全大写小标题、外框。

## 8. 自动检查

`python -I design/check_mockups.py design`：每个视觉稿 × 3 尺寸 × 浅 / 深色截图到 `design/screenshots/`，并断言：无控制台错误；无外网请求；歌词网格顶边在视口一半以内；没有 `text-transform: uppercase`；主强调色色相不在 250–310°；主要文字（标题、`[data-contrast]`、歌词字）对比度 ≥ 4.5:1；深色模式确实生效。任何一项不满足退出码 1。

反证：`python -I design/evidence/run_negative_checks.py design` 把视觉稿分别改成紫色强调色、网格挪到首屏以下、标题全大写、引外网字体、打 console.error、歌词字浅灰、删掉网格、深色失效，8 条全部让检查变红，记录在 `design/evidence/negative_checks.md`。

## 9. 需要你确认的决定

1. **强调色用朱橙**（不是 Alphie 的 indigo，也不是紫色）。备选：青绿、Alphie indigo。
2. **一行一小节、一格一个 1/16**；旧工程「一拍一格」的数据导入时平均摊开（见清单 #9）。备选：保留「一拍一格 + 字数决定细分」。
3. **伴奏不再单独播放**，统一到一个播放键（清单 #6）。
4. **4 个节拍圆点去掉**，由网格高亮和位置数字代替（清单 #2）。
5. **AI 模型选择和 Key 交给 Alphie Worker**，页面里不再放模型下拉和 Key（清单 #20）。
6. **长篇使用说明去掉**，换成状态栏快捷键（清单 #23）。
7. **右侧面板而不是底部面板**（桌面）：999 宽下网格占 ~700px，够 16 格 + 行尾韵母；底部面板会把首屏网格压到 5 行以内。
8. **手机上面板是 270px 底部抽屉**，不在焦点的段落自动折叠。
9. **自动保存改为改动后 2 秒**，不需要先命名作品（新作品默认叫「未命名 1」）。
10. **同韵候选默认本地韵表**，主题联想继续走现有本机向量服务（可选、可离线）。
