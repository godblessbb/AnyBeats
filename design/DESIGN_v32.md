## 1. 为什么现在第 1 步写不了字、也回不到空表格（在 v3.1 代码里查到的）

- 第 1 步点格子走 `LyricsGrid.tsx` 的 `onCellClick → store.flowClick(tick)`：按精度吸附**放一个空字**（`core/flow.ts` 的 `placeWord`），
  点到已有的字只是 `focusWord` 选中它（给拖长、`-` / `⌫` 用）。第 1 步**没有任何输入框**；双击改字（`editCell`）只在第 2 步接。
- 第 1 步按 `⌫` 是 `deleteCursorWord`：把字删掉（留下空音），不是删文字。
- 想重来只有每一行的「清空这一行」（`clearBarFlow`），而且清完是**完全空的一行**（没有字），不是「每拍一个」。
- 新作品 `createGrid()` 的小节里一个字都没有，所以第 1 步一打开是空白表格，看不出哪里该有字。

## 2. 方格怎么对到现在的 tick 数据模型（不改数据格式、不改存档）

数据还是 v3 的：每个字 `{ tick（小节内起点）, len（持续多少 tick）, text }`，每拍 48 tick。**不加任何新字段**。

| 看到的 | 数据里是什么 |
|---|---|
| 方格 | 一个字（`Word`）。空方格 = `text === ''`；写了字的方格 = `text` 是一个字 |
| 方格画多宽 | 这个字在它起点那一拍里的长度：`box = min(len, 48 − tick % 48)` |
| 拖音 | 字的 `len` 超过拍线的那部分，照旧画成同色浅底（v3.1 画法不变），拖到下一拍 / 下一行 |
| 空音 | **没有字**——字和字之间的空白（和 v3 一样不存）。画面上什么都不画 |
| 1/4、1/8、1/16、1/32 | box = 48、24、12、6 tick |
| 三连 / 半拍三连 | box = 16 / 8 tick；格子上方标「3」（整拍三连标整拍，半拍三连标那半拍） |
| 默认（每拍一个方格） | 一小节 4 个字：tick 0 / 48 / 96 / 144，len 48，text 空 |

### 2.1 操作 = 纯函数（第二段加在 `core/grid.ts`，都只动这一拍里的字，**永远不碰下一拍的字**）

- **一分为 n（n = 2 空格 / 3 Shift+空格）** `splitSquare(grid, abs, n)`：设方格 box = b、每块 u = b / n。
  - u 必须是整数而且 **≥ 6**（1/32 是最细的）：48→24→12→6 可以，6 再分被拒；三连：48→16、24→8 可以，12、16、6 再三连被拒（分不出整数或比 1/32 还细）；
    三连格（16）再按空格 → 两个 8 可以，8 再分 → 4 被拒。被拒时什么都不改，提示「已经是 1/32，最细了，不能再分」（三连的另有一句「这么短的格子分不成三连」）。
  - 第一块沿用原来的字（id、**文字留在左边**），其余是新的空方格；原来拖过拍线的长度（拖音）跟着**最后一块**走（它的结束位置不变）。
- **变成空音** `restSquare(grid, abs)`：删掉这个字（它拖过拍线的拖音也一起没了）。前面拖进来的字不动。
- **合并（空方格按 ⌫）** `mergeSquare(grid, abs)`：找它的「另一半」——
  - 二分出来的（u = 24 / 12 / 6，或三连里再二分的 8）：起点 `off` 在这一拍里 `(off / u)` 是偶数 → 另一半在右边 `off + u`，奇数 → 在左边 `off − u`；
  - 三连的一块（16，或半拍三连的 8 且不是二分来的）：三块合成一个；
  - 另一半是**空音** → 这个方格把那段空白也占上（等于把空音变回方格）；
  - 另一半还分得更细（不是同样大小的一个方格）→ 不合，提示「旁边那一半分得更细，先把它合回来」；
  - 整拍一个方格（box 48）→ 不合，提示「整拍一个方格，不能再合；要空音按两下空格」。
  - 合出来的方格用左边那块的字和 id；左边是空的就用右边那块的字。
- **点空白（空音 / 拖音上）**：照 v3.1 的放字规则——按工具条上的精度吸附放一个方格（长一个精度单位），然后进入改字；
  前面拖进来的拖音被截到新方格开头。（稿子阶段写的是「最大对齐块」，实现时改成沿用 v3.1 规则：精度按钮仍然有用，
  而且 v3 / v3.1 的「点空白放字」检查原样成立。）
- **光标停在空音上打字** `fillRest(grid, abs, len, text)`：放回一个和这段空音一样大的方格并写上字。
- **清空全部 flow** `resetFlow(grid)`：段落、小节（连小节 id）都留着，每一小节换成默认 4 个方格；文字、拖音、分格全清掉。
- **写字** `setSquareText`（就是现有的 `setWordText`）：一格一个字，再打一个字就替换。

### 2.2 历史（撤销 / 重做）

每个操作 `editorStore.exec(...)` 一次 = 历史里一步（一分二、三连、空音、合并、写一个字、清空全部 flow 都各算一步），`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` 照常。
锁定检查照旧走 `exec`：碰到锁住的字整步不做、出提示（清空全部 flow 也一样：有锁住的字就整步不做，提示先解锁）。

**两下空格只算一步**：第一下空格照常 `exec` 一分二（画面上会闪一下两个方格）；0.4 秒内第二下空格到来时，
`editorStore` 先把刚才那一步**从历史里撤掉**（`history.undo()`，它后面的重做分支随后被新的一步覆盖），再 `exec` 一步「变成空音」。
最后历史里只多了一步「第 n 小节第 m 拍 … → 空音」，`Ctrl+Z` 一次就回到按空格之前（一个完整的方格），重做一次又回到空音。
第一下空格如果被拒（例如在 1/32 上），第二下照样把它变成空音（还是一步）。

## 3. 键盘状态机（只在第 1 步的改字状态里接管按键）

改字状态 = 光标在一个方格（或一段空音）上，焦点在一个**看不见的输入框**里（真焦点，输入法才能用）；它贴在光标方格上。

| 状态 | 输入 | 结果 |
|---|---|---|
| 空闲（没点方格） | 点方格 | 进入「改方格」，光标在这一格 |
| 空闲 | 点空白（空音 / 没有字的地方） | 按精度放一个方格（一步，v3.1 规则），进入「改方格」 |
| 空闲 | 空格 | 播放 / 暂停（和现在一样，不变） |
| 改方格 | 打字（`input` 事件，不在拼字中） | 写进这一格（一步）；一次上屏多个字（输入法整词）→ 从这一格起往后依次填**这一拍里**的方格，放不下的不写、提示；光标留在这一格 |
| 改方格 | 空格（没按 Shift） | 一分二（一步），光标在左边那块；记下「等第二下」：时间 = 这次 keydown 的 `timeStamp`，目标 = 原来那一格 |
| 等第二下（≤ 400 ms，同一个目标，中间没按别的键） | 空格 | 撤回刚才的一分二 + 变成空音，合计一步；光标停在空音上 |
| 等第二下 | 超过 400 ms 才来的空格 | 当成新的一下：再分一次左边那块（不变空音） |
| 等第二下 | 别的键 / 点别处 | 不再等，按那个键本来的意思处理 |
| 改方格 | Shift+空格 | 三连（一步），光标在第一块；不进「等第二下」 |
| 改方格 | `⌫` / `Delete` | 方格有字 → 清掉字（一步）；空方格 → 合并（一步）；不能合 → 提示 |
| 改方格 | `Tab` / `→`（`Shift+Tab` / `←`） | 光标去下一个（上一个）方格，可以跨拍、跨小节 |
| 改方格 | `-` / `=` | 拖长 / 缩短一个精度单位（v3.1 行为不变） |
| 改方格 | `Enter` / `Esc` / 点别处 | 退出改字 |
| 改方格 | `Ctrl+Z` 等 | 撤销 / 重做（输入框里自己接，因为全局快捷键碰到输入框不接管） |
| 改空音 | 打字 | 放回一个方格（大小 = 这段空音）并写上字，一步 |
| 改空音 | `⌫` | 和旁边那一半合并（空音被方格占上） |
| **任何状态，输入法在拼字**（`e.isComposing` 或 `keyCode === 229`） | 空格 / `⌫` / `Enter` | **什么都不做**，交给输入法（选字、删拼音、上屏）；也不进「等第二下」 |

- 空格的 keydown 一律 `preventDefault`，输入框里不会出现空格字符；输入框每次写完清空。
- 0.4 秒用 keydown 的 `event.timeStamp` 量，不靠 `setTimeout`；e2e 里用真实按键 + 等待来测 0.3 s / 0.6 s 两种间隔。
- 手机：软键盘的空格一样用；另外气泡里有 **一分二 / 三连 / 空音 / 合并** 四个按钮（桌面上也有，和按键是同一件事），
  这一格不能做的按钮置灰（例如 1/32 上的「一分二」、整拍方格上的「合并」）。

## 4. 画法（稿子里的样子）

- **空方格**：实线边（App 里已有的 `--slot-line`，就是 v3 字位框的颜色）+ 一层浅灰底（`--slot-line` 混 16% 进 `--slot-bg`），左右各留 2px 缝。
- **写了字的方格**：细一点的边、白底（深色模式是深底），字靠左写在格子里；韵脚字照旧用它那种颜色加粗。
- **空音**：什么都不画（没有边、没有底），一眼就和方格分开；光标停在空音上时画一圈强调色**虚线**，宽的写「空音」。
- **光标所在方格**：2px 强调色边 + 一圈浅色光晕 + 一条强调色竖线光标。
- **拖音**：v3.1 的同色浅底，从拍线接着铺（没有边线），所以和方格也分得开。
- **三连**：格子上沿一条细括线 + 「3」（v3 已有的样式）。
- 「清空全部 flow…」：第 1 步工具条最右边，红色字的幽灵按钮（和「清空当前文字…」同款）；点了变成一条警告色描边的确认条：
  「每一拍变回一个方格？段落和小节留着，字和拖音清掉，可以撤销。」+ 红底「清空」+「取消」。手机上工具条折成两行，确认条占满一行。
- 第 2 步**不画方格**（v3.1 的样子不变）：空字照旧是一条短下划线。
- 只用已有的颜色 token（强调色朱橙、`--slot-*`、警告色、`--a-error`），没有新配色；浅 / 深色、桌面 / 手机都截了图。

## 5. 和 v3.1 冲突的地方（第二段按这里改，交付时写进报告）

1. **第 1 步单击**：v3.1 = 按精度放一个空字 / 点字只选中；v3.2 = 点方格进入改字，点空白照旧按精度放一个方格并进入改字。
   工具条上的精度按钮从此**只管拖长度吸附**（拖浅底右边缘、`-` / `=`），不再管点哪里放字。
2. **第 1 步 `⌫`**：v3.1 = 删掉选中的字（留下空音）；v3.2 = 先清字，空方格再按是合并。要空音用两下空格。
3. **第 1 步改字状态里的空格**：是分格，不是播放；没在改字时空格照旧播放 / 暂停。
4. **新作品、清空全部 flow 之后每拍一个方格**（合同原话只列了这两处）。「+ 小节」「+ 段落」加出来的小节照旧是空的（空音），点一下放方格——
   这样 v3.1「整列只选有东西的格子」「加一段空的 Outro」不受影响。新作品每格都有方格，所以整列选中会选到每一格；
   「一个字都没写就打开在第 1 步」不受影响（方格没有字）；换伴奏时只有默认方格、没写字的作品照旧当空工程（不弹 BPM 窗）。
   已经存的旧作品**不动**：里面原来空着的拍打开后就是空音（空白），点一下就放回方格。
5. 第 2 步（双击改字、打 1–4 个字自动平分、涂色押韵、韵脚检查）**一行不改**。拖动字挪位置**不做**（用户说先不做）。
6. `e2e/check_app_v3.py`、`check_app_v31.py` 里凡是靠「第 1 步单击放字」「第 1 步 ⌫ 删字」「新小节是空的」的断言，第二段换成等价的新行为检查，并在文件开头逐条写原因。
