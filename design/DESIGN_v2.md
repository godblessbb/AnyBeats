## 1. 新的写词流程（一句话版）

**草稿里先把整段写完 → 点「铺到拍子上」→ 网格里拖字微调 → 在轨道区录几遍、挑一遍。** 草稿和网格随时来回切换（顶栏「草稿 | 网格」），微调不会因为切回草稿而丢。

## 2. 十项改动逐项说明

### 1）草稿视图（重点）
- **改了什么**：新增「草稿」视图，和「网格」并列，顶栏左边一个分段按钮切换（手机在第二行工具条）。草稿就是一个大文本框：一行一句，写「【副歌】」这样的一行开新段落。每句末尾实时显示句尾韵母标签和字数，句内同韵字也着色（和网格同一套颜色）。底部一个大的主按钮「铺到拍子上 →」，左边写清铺法：**每字一格（1/16），空格变一格空拍，句尾最后一个字延音两格，一句铺成一小节**。铺完自动切到网格，顶上一条绿色提示「已铺成 10 小节……拖动字可微调；切回草稿改字，没改的句子保留微调」，旁边「撤销铺放」。
- **切回草稿时微调怎么保留**（`draft_back.html`）：按句比对。没改字的句子 → 网格里的手动微调原样保留（行尾标「已微调 · 保留」）；改了字的句子 → 再铺时只重铺这一句（行尾标「改了字 · 重铺这一句」），其它句不动；按钮文字变成「铺到拍子上（重铺 1 句）」。重铺可以撤销。这条规则列在拍板题 2。
- **为什么**：写词通常先有句子再对节奏；现在必须先把每个字塞进 1/16 格才能写，顺序反了。
- **落在**：`draft`、`draft_back`、`empty`（空草稿）、`grid`（铺完提示 + 拖动微调）。

### 2）押韵着色（重点）
- **改了什么**：
  - **句内同韵同色**：一句里所有和句尾押同一个韵（十三辙，和代码里 `src/core/rhyme` 的分组一致）的字都着同一种颜色，不只句尾。例：第 1 句「街**上** 我还在路**上**」两个「上」都是蓝；第 5 句「**穿**过霓虹 向**前**」两个都是绿。
  - **双押 / 多押连成一块**：相邻两三个字和另一句的相邻几个字都押上时，这几格连成一块，外面一个同色圆角框，框上标「双押」（三个字标「3 押」）。例：「理想 / 地方」「失眠 / 时间」。
  - **句尾不押的提示**：两句句尾不押时，后一句的韵母标签变成**虚线框 + 暖色字**「ing · 和上句 ai 不押」（主歌 2：「台」ai /「径」ing），不用红色、不闪。右侧押韵面板也写一句「上一句句尾『台』是 ai（怀来），这两句没押上」，并给「押本句 ing / 押上句 ai」两个按钮，选「押上句」就列出 ai 的候选。
  - **图例**：网格上方一行，写清「同色＝押同一个韵」、四个韵部的颜色样例、「框住＝双押 / 多押」「虚线＝和上句不押」「加粗＝重音」「灰格＝空拍」。
  - 颜色只上在底色和底部色条上，字始终是正文色（对比度 ≥ 4.5:1）；色板避开紫色区。
- **为什么**：只标句尾看不出句内韵和多押，而这正是说唱写词最在意的。
- **落在**：`grid`、`record`（网格）、`draft`、`draft_back`（草稿里同一套着色）。

### 3）伴奏空态（重点）
- **改了什么**：没载入伴奏时，轨道区整块（桌面约 130px 高、手机约 280px 高）变成二选一引导：左边是虚线拖放区「拖入伴奏文件」+ 主按钮「选择伴奏文件」（mp3 / wav / m4a，载入后自动检测 BPM）；中间一个「或」；右边「先用节拍器写」+ BPM 步进 + 按钮「用节拍器开始」。底下一行小字「伴奏只读进本机浏览器，不上传」。手机上两块上下排列，按钮通栏。
- **为什么**：现在只是时间轴上一条细虚线，第一次打开不知道从哪开始。
- **落在**：`empty`。

### 4）网格每拍分组
- **改了什么**：每 4 格（一拍）的分界是 **2px 深色竖线**，拍内是 1px 很浅的线；同时**第 2、4 拍整列加一层很淡的底**（隔拍交替）。网格顶上标 1 / 2 / 3 / 4 拍号。
- **为什么**：16 格一样粗的时候数不清字在第几拍。
- **落在**：`grid`、`record`。

### 5）去掉自造符号
- **改了什么**：重音字**直接加粗**（不再在字下画小圆点）；空拍格**留空 + 浅灰圆角底**（不再显示「∅」）；延音仍是一条连到前一个字的横线（和钢琴卷帘一样，不是新符号）。
- **为什么**：小圆点和 ∅ 都要先学才看得懂。
- **落在**：`grid`、`record`；图例里有说明。

### 6）空间利用
- **改了什么**：歌词字号 16px → **20px**（手机 14px → 16px），格宽 34px → 50px（手机 19px → 22px），行高 42px。韵母标签**紧贴句尾**放在最后一个字（含延音）后面，不再在右边单独留一栏；草稿里同样紧跟在句子后面。
- **为什么**：原来字小、右侧一大片空白。
- **落在**：所有画面。

### 7）押韵面板重排
- **改了什么**：右栏只剩押韵一个面板，从上到下：**① 当前句尾**（大字「径」+ 拼音 + 韵部，不押时的提示和「押本句 / 押上句」）→ **② 筛选收成一行**（字数 / 声调 / 词性三个下拉）→ **③ 候选结果**（三列网格，占面板主要面积，可滚动，底部渐隐 + 滚动条）→ **④ 主题联想**（输入框 + 换一批，注明「候选来自本机韵表，不联网」）。
- **候选词后面的数字去掉了**（原来那个数字是末字声调，代码里是 `RhymePanel.tsx` 的 `w.tone`，不写说明谁也看不懂；声调已经在筛选里了）。
- **为什么**：原来筛选占了三四行，候选被挤成一小块，顺序也不是写词时看的顺序。
- **落在**：桌面所有画面右栏；手机抽屉展开后同样顺序（这一单只画收起态，见残留风险）。

### 8）静态版隐藏 AI
- **改了什么**：不显示「AI 写词」页签，不显示 Worker 状态（顶栏和面板都没有）。
- **以后接上 AI 时它出现在哪**：右栏顶部出现「押韵 | AI」两个页签（只有连上 Worker 时才出现）；Worker 状态只在 AI 页签里显示，不回到顶栏；草稿每行和网格每行的「⋯」菜单里加「让 AI 续写 / 改押韵」。手机上是抽屉里的第二个页签。
- **为什么**：静态版不接 AI，显示一个永远「未连接」的东西只会让人以为坏了。
- **落在**：所有画面（检查脚本断言可见文字里没有「Worker」「AI 写词」）。

### 9）段落名统一语言
- **改了什么**：全部用中文：前奏 / 主歌 / 副歌 / 桥段 / 尾奏（示例里原来的「Hook」改成「副歌」）。网格段落头、轨道区标尺、草稿【段名】行一致；空草稿的提示里列出这五个名字。
- **为什么**：「Hook」和「主歌」混在一起显得乱。全部中文还是全部英文由你定（拍板题 1）。
- **落在**：所有画面。

### 10）录音音轨 + 手机底部
- **改了什么**：录音不再藏在右栏页签里。轨道区固定有一行「人声」，左边是录音键（没录过叫「录音」，录过 3 遍叫「录第 4 遍」），录下的每一遍是这一行下面的一条音轨：**左边「第 n 遍」+ 选用标记（橙色「✓ 选用」或「点一下设为选用」）+ 时长，右边是对齐时间轴的波形**；选用的那一遍整条浅橙底，两端括号裁头尾（斜纹是被裁掉的部分）。延迟补偿和「重新校准」写在人声行里，输入电平在右边。
- **手机**：押韵抽屉默认收起，只露一条 56px 的把手（「押韵 · 径 · ing · 上句 ai 不押 · 上滑看候选」）；**底部只有这一层**，原来的五个页签（写词 / 押韵 / AI / 录音 / 工程）去掉：草稿/网格切换放到第二行工具条，录音在轨道区，作品与导出在顶栏右上角。
- **为什么**：录音键和录下来的东西不在一处，找不到；手机底部原来叠了两层（候选条 + 页签栏），把歌词挤得很少。
- **落在**：`record`（3 遍）；其它画面的人声行；所有手机画面的底部。

## 4. 需要你拍板的题

1. **段落名：全部中文还是全部英文？**
   - A（视觉稿现在的做法，推荐）：前奏 / 主歌 / 副歌 / 桥段 / 尾奏。界面文字本来就要求中文。
   - B：Intro / Verse / Hook / Bridge / Outro。说唱圈习惯说 Hook / Verse，但会和其它中文界面混排。
2. **草稿切回网格时，手动微调怎么保留？**
   - A（视觉稿现在的做法，推荐）：**按句比对**。没改字的句子保留微调；改了字的句子整句重铺（这一句的旧微调丢掉，可撤销），其它句不动。规则简单、好解释。
   - B：改了字的句子也尽量保留：没变的字留在原位置，只给新增 / 删掉的字重新排。保留得更多，但改字后位置可能乱，难以预期。
   - C：每次铺都全部重铺。最简单，但微调全丢。
3. **双押块用什么颜色？**
   - A（视觉稿现在的做法，推荐）：用这句句尾韵的颜色（例如「理想」整块蓝色，「理」虽然是一七辙也跟着蓝），外加同色框和「双押」小字。一句只有一种主色，不花。
   - B：块里每个字按自己的韵上色（「理」金、「想」蓝），只用框把它们圈起来。信息更全，但一句里颜色变多。
   - C：双押块统一用一个专门的颜色（例如金色），和韵部色分开。
4. **句内着色的范围**：现在只给「和本句句尾同韵」的字着色，加上双押块；句内碰巧同韵、但和句尾不同韵的字（例如第 1 句「还在」都是怀来辙）不着色，免得满屏是颜色。要不要也标？
5. **手机底部只留押韵把手、导航挪到上面**：备选是把「草稿 / 网格 / 押韵」做成底部一条三格导航、押韵点开是抽屉。现在的做法歌词区更高。
6. **铺法默认值**：每字一格（1/16）、空格成一格空拍、句尾延音两格。备选「每字两格（1/8）」适合慢歌，放在铺法下拉里。
