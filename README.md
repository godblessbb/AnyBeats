# 🎤 AnyBeats - Rap 创作工具

一个专为 Rap 创作设计的节奏与歌词同步工具，帮助你在节拍中创作完美的韵律。

## ✨ 功能特性

### 🥁 节拍器
- **可调节 BPM**: 支持 60-180 BPM 的速度调节
- **视觉节拍指示**: 四个节拍点的实时动画显示，强拍与弱拍区分明显
- **节拍音效**: 可选的音效功能，强拍和弱拍使用不同音高
- **播放/暂停控制**: 一键开始或停止节拍

### 📝 歌词创作区
- **可视化时间轴**: 基于小节的网格布局，每个小节 4 拍
- **灵活的歌词块**:
  - 点击任意位置创建歌词块
  - 双击编辑歌词内容
  - 支持多种时长：1/4拍、1/2拍、1拍、2拍
- **智能文字大小**:
  - 1拍或更长: 24px（大字体）
  - 1/2拍: 20px（中等字体）
  - 1/4拍: 16px（小字体）
  - 内容过多时自动缩小（最小 12px）
- **实时播放高亮**: 播放时当前演唱的歌词块会高亮显示
- **精细控制**: 选中歌词块后可调整时长、删除等

## 💡 使用方法

1. **启动节拍器**
   - 点击中央的播放按钮 ▶️ 开始打拍
   - 使用滑块调整 BPM 到你想要的速度
   - 勾选"节拍音效"启用声音提示

2. **创作歌词**
   - 在歌词创作区的网格上点击任意位置创建歌词块
   - 双击歌词块输入你的歌词
   - 选中歌词块后，在下方控制面板调整时长

3. **调整与编辑**
   - 选择不同的时长按钮来调整歌词块的长度
   - 文字大小会自动根据时长和内容调整
   - 点击删除按钮移除不需要的歌词块

4. **实时预览**
   - 节拍器运行时，当前位置的歌词块会高亮显示
   - 帮助你感受歌词与节奏的配合

## 🎨 技术栈

- **React 18**: 现代化的用户界面
- **TypeScript**: 类型安全的代码
- **Vite**: 快速的开发构建工具
- **Web Audio API**: 高质量的节拍音效

## 📱 响应式设计

- 支持桌面端（1024px+）：左右布局
- 支持平板和移动端：上下堆叠布局
- 所有屏幕尺寸都有优化的用户体验

## 🎵 交互设计理念

- **直观操作**: 点击创建，双击编辑，简单易懂
- **视觉反馈**: 丰富的动画和颜色变化，实时响应用户操作
- **节奏优先**: 文字大小随节拍时长变化，强化节奏感
- **自适应**: 内容过多时自动调整，保持视觉平衡
